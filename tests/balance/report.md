## How to read this

- `truncated` means the run used the whole frame cap, so its numbers are a floor on progress, not a finish. Raise `BALANCE_FRAMES` to look closer.
- `stalled` means the run stopped on a state the harness does not drive (a cutscene, a reward screen). That is a harness limitation, not a game freeze.
- A cell that never reaches a shop is not a balance bug: the bot only spends at camp, and camp opens when a floor is cleared.
- Ability use is counted by the harness because the game keeps no per-run counter for it.
- The bot has no pathfinding. It beelines at the nearest enemy, so a wall between them means no damage that frame. Its numbers compare cells against each other; they do not predict how a human plays.
